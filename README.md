# NextBites 🍴

A simple and responsive recipe discovery website built with Next.js and TypeScript.

## About the Project

NextBites is a recipe homepage designed to help users discover different meals through a clean, simple, and responsive interface.

## Features

- Responsive homepage layout
- Recipe cards displaying food, recipe name, preparation time, difficulty, and cuisine
- Reusable React components
- TypeScript-based recipe data
- Responsive CSS Grid layout

## Technologies Used

- Next.js
- React
- TypeScript
- CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/jitenkiran/NextBites.git
```

Navigate to the project folder:

```bash
cd NextBites
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the website.
